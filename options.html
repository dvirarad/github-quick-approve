GitHub Quick Approve

Paste a GitHub personal access token. It's stored only in this browser (chrome.storage.local) and sent only to api.github.com.

  • Fine-grained token: repository permission Pull requests: Read and write, covering the repos you review.
  • Classic token: the repo scope. If your org uses SSO, click Configure SSO → Authorize on the token.
